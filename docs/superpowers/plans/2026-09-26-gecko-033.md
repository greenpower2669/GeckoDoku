# GECKO-033 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax.

**Goal:** Integrate the new GeckoDoku identity assets, synchronize `ProfParle.mp4` to Pierre's real speech lifecycle, mute Gecko animation videos, chain the two intros, and add low-priority contextual Pierre speech with exactly 100 Gecko small-talk lines.

**Architecture:** Keep GameEngine and board geometry untouched. Add small pure Kotlin policy/state classes for testable behavior; wire them into MainActivity and the existing ProfessorSpeech/media layer. Reuse the existing Prof video host as a single exclusive player with ACTION and SPEECH modes so `Prof_actions.mp4` and `ProfParle.mp4` can never overlap.

**Tech Stack:** Android/Kotlin, JUnit 4, Sherpa-ONNX/Piper, MediaPlayer/OpenGL ChromaKeyVideoView, GitHub Actions.

**Spec:** `ordres-de-mission.md` — GECKO-033 plus addenda through marker `GECKO-033-PROFPARLE-SPEECH-LIFECYCLE-2026-09-26`.

## Global Constraints

- Do not modify GameEngine, Puzzle, solver rules, difficulty logic, or board geometry.
- `IconGeckoGD.png`, `IntroGeckoGD.mp4`, and `ProfParle.mp4` stay unmodified and unmoved.
- Pierre remains Piper/Sherpa UPMC Medium speaker `sid=1`; Android TTS remains fallback.
- `Prof_actions.mp4` is general/idle Prof animation; `ProfParle.mp4` is speech-only.
- Gecko animation video audio is always muted; dedicated MP3 music remains independent.
- `ProfParle.mp4` stops on real speech end/cancel/error and restarts from t=0 after a silence; if its 30 s clip ends while Pierre is still speaking, it loops by restarting from t=0.
- FAB Copilot five living files are synchronized in every implementation cycle.
- Final acceptance requires CI tests + APK + AAB green, then phone validation by Fab.

## Review Focus

- Speech replacement while a previous utterance is active must stop the visual before the next real audio start.
- Fallback Android TTS must generate the same speaking-state callbacks as Piper.
- Intro skip must reveal the already-created game without starting the second intro.
- Gecko videos must remain muted even when FX is ON.
- Ambient Pierre must never interrupt explicit Prof help, intro, victory, dialogs, or another utterance.
